# Portfólio

Aplicação de portfólio pessoal desenvolvida com React + Vite, com interface moderna e seções de apresentação profissional, experiências, habilidades, projetos, formação e contato.

## Tecnologias

- React 18
- Vite 6
- Tailwind CSS
- Framer Motion
- Lucide React

## Pré-requisitos

- Node.js 18+ (recomendado)
- npm 9+ (ou compatível)

## Como executar localmente

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

3. Acesse no navegador:

```text
http://localhost:5173
```

## Build de produção

```bash
npm run build
```

Para pré-visualizar o build:

```bash
npm run preview
```

## Estrutura principal

```text

  components/
  App.jsx
  main.jsx
  index.css
public/
```
